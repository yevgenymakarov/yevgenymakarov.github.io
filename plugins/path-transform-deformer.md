# Path Transform

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Path.Transform.Deformer.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Deformer Layer that applies transformations (rotation, scale, skew) to Shape's path while maintaining the stroke width.

## User Manual

**Strength** - Determine the strength of the Deformer.

**Position** - Set the position.

**Rotation** - Set the rotation (in degrees).

**Scale** - Set the scale values.

**Skew** - Set the skew values.

**Recalculate Pivot** - Place the pivot for path based on the Pivot Position.

**Pivot Position** - Position the pivots by aligning them to path's bounding box.
