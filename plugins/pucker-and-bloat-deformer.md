# Pucker and Bloat

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Pucker.and.Bloat.Deformer.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Deformer Layer that pushes the Shape's points inward or pulls them outward while curving the segments.

## User Manual

**Strength** - Determine the strength of the Deformer.

**Pivot** - Define the pivot point of the transformation.
