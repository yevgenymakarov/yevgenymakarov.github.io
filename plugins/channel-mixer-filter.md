# Channel Mixer

> Version 1.0.0
> Supports Cavalry 2.4.3 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Channel.Mixer.Filter.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Filter Layer that replaces the red, green, blue, and alpha channels with mixed values from the original channels.

## User Manual

The tabs identify the targeted (output) color channel to which the adjustment will be applied. The sliders control the contribution of the named color channel to the selected output channel.

**Red** - Control the contribution of the Red channel to the output (Red, Green, Blue, or Alpha) channel.

**Green** - Control the contribution of the Green channel to the output (Red, Green, Blue, or Alpha) channel.

**Blue** - Control the contribution of the Blue channel to the output (Red, Green, Blue, or Alpha) channel.

**Alpha** - Control the contribution of the Alpha channel to the output (Red, Green, Blue, or Alpha) channel.

**Offset** - Control the overall contribution to the output (Red, Green, Blue, or Alpha) channel.
