# Wave Warp

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Wave.Warp.Deformer.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Deformer Layer that applies the wave effect traveling across a Shape.

## User Manual

**Strength** - Determine the strength of the Deformer.

**Wave Height** - The height of the wave in pixels.

**Wave Width** - The width of the wave in pixels.

**Direction** - The direction of the wave.

**High Quality** - Geometry will be sampled to a higher quality, at the expense of performance.

**Time** - An auto connection to the Composition's time.

**Time Offset** - Offset the animation/time.

**Time Scale** - A multiplier for time.
