# Linear Brightness and Contrast

> Version 1.0.0
> Supports Cavalry 2.4.3 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Linear.Brightness.and.Contrast.Filter.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Filter Layer that adjusts the brightness and contrast of a Layer using linear (legacy) transfer functions.

## User Manual

This is not recommended for photographic images but can be useful for editing masks or other technical purposes.

**Blend Mode** - Set the blend mode for the Filter.

**Opacity** - Set the Alpha of the image.

**Brightness** - Set the brightness value.

**Contrast** - Set the contrast value.
