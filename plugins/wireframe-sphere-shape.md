# Wireframe Sphere

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Buy Now](https://app.lava.top/products/15f7e59d-5101-4bc2-9281-5cd10c9f06d1 "Go to the store")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Shape Layer that creates an animatable globe-like sphere, with the option to cut the sphere and create a coin-like shape.

<img width="980" alt="Wireframe Sphere" src="../images/wireframe-sphere-shape.png">

## User Manual

**Radius** - Set the radius of the sphere.

**Tilt** - Set the tilt and rotation of the sphere.

**Meridians** - Set the number of meridians to be drawn.

**Parallels** - Set the number of parallels to be drawn.

**Even Distribution** - Evenly distribute the parallels, rather than sinusoidally.

**Slice** - Create a slice on the sphere. Set the level of the sphere's cut as a percentage of its height.

**Two Slices** - Create symmetrical slices on both sides.

<img width="900" alt="Wireframe Sphere" src="../images/wireframe-sphere-screenshot.png">

The Shape is split into five sub-meshes, allowing you to set different styles for individual parts of the sphere using Sub-Mesh behaviour. It contains sub-meshes of meridians, parallels, and outline contour for the stroke style, as well as sub-meshes of the body and slice cap for the fill style.
