> Supports Cavalry 2.6.0 and later.

{: .py-3 .bg-gray .rounded-2 }

This plugin is a Deformer Layer that visualizes the points and handles of a bézier curve.

<img width="860" alt="Path Visualizer" src="../images/path-visualizer-deformer.png">

## User Manual

**Strength** - Determine the strength of the Behaviour.
  
**Draw Bézier Handles** - Add lines to visualize bézier handles.
  
**Strength Fade Bézier Handle** - When checked, the Strength and Falloffs affect the length of the visualized bézier handles.

**Point Shape** - The shape (circle, square, or diamond) is how bézier points are visualized.

**Point Radius** - The radius of the visualized bézier points.

**Strength Fade Point Radius** - When checked, the Strength and Falloffs affect the radius of the visualized bézier points.

**Control Point Shape** - The shape (circle, square, or diamond) is how bézier control points are visualized.

**Control Point Radius** - The radius of the visualized bézier control point.

**Strength Fade Control Point Radius** - When checked, the Strength and Falloffs affect the radius of the visualized bézier control point.

**Keep Original Path** - Preserve the original path in the output.

**Use Materials** - When unchecked, the appearance is inherited from the Shape's Fill and Stroke settings.

**Bézier Handle Stroke** - Set the bézier handle stroke color.

**Bézier Handle Stroke Width** - Set the bézier handle stroke width.

**Point Fill** - Set the bézier point fill color.

**Point Stroke** - Set the bézier point stroke color.

**Point Stroke Width** - Set the bézier point stroke width.

**Control Point Fill** - Set the bézier control point fill color.

**Control Point Stroke** - Set the bézier control point stroke color.

**Control Point Stroke Width** - Set the bézier control point stroke width.
