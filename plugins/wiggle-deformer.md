# Wiggle

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Wiggle.Deformer.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Deformer Layer that applies the wiggle effect to a Shape by moving the path points with noise.

## User Manual

**Strength** - Determine the strength of the Deformer.

**Amplitude** - Set the amplitude of the displacement.

**Wavelength** - Set the noise frequency.

**X Axis** - Apply deformation in the horizontal direction.

**Y Axis** - Apply deformation in the vertical direction.

**Time** - An auto connection to the Composition's time.

**Time Offset** - Offset the animation/time.

**Time Scale** - A multiplier for time.
