# Chevron Shape

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Chevron.Shape.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Shape Layer that creates a chevron shape (V-shaped symbol).

<img width="800" alt="Chevron Shape" src="../images/chevron-shape.png">

## User Manual

**Type** - The style of the chevron's leg.

**Length** - The length of the chevron's legs.

**Width** - The width of the chevron's legs.
