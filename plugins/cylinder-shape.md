# Cylinder Shape

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Cylinder.Shape.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Shape Layer that creates an animatable cylinder in orthographic projection.

## User Manual

**Height** - Set the height of the cylinder.

**Radius** - Set the radius of the cylinder.

**Tilt** - Set the rotation of the cylinder.

**Offset** - Set the position of the cylinder.

**Pivot Position** - Set the position the pivot by aligning it to the cylinder's bounding box. Affects the direction of the cylinder's size change.

**Per-Face Colors** - Use custom fill colors for each surface. When disabled, the Shape's Fill and Stroke settings are used.

**Top** - Set the color of the top base.

**Side** - Set the color of the side surface.

**Bottom** - Set the color of the bottom base.
