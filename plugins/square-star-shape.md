# Square Star

> Version 1.0.0
> Supports Cavalry 2.6.0 and later.
> **[Free Download](https://github.com/yevgenymakarov/yevgenymakarov.github.io/releases/download/v1/Square.Star.Shape.zip "Download the zip file")**
{: .py-3 .bg-gray .rounded-2 }

This plugin is a Shape Layer that creates a star-like shape with square points.

<img width="800" alt="Square Star" src="../images/square-star-shape.png">

## User Manual

**Radius** - The radius of the base polygon before cut-off.

**Sides** - The number of squared points.

**Cutout** - Controls the width of the squared points.
